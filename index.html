KARTBRAVO

Jogo de kart para Android: oficina, chuva, corridas com amigos no Wi-Fi, Bluetooth ou pela internet, e rádio entre os pilotos.

Baixar para Android
  1. Toque em Baixar para Android.
  2. Abra o arquivo baixado. Se o Android pedir, permita instalar apps desta fonte.
  3. Depois disso, o jogo se atualiza sozinho quando sair versão nova.
